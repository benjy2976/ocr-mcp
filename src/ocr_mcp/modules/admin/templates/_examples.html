Cómo se conecta un cliente

Se agrega el servidor con su URL, sin claves en la configuración. En la primera conexión, el cliente abre el navegador y la página pide la clave de acceso.

URL del servidor: {{ mcp_url }}

Claude Code

claude mcp add --transport http ocr {{ mcp_url }}

Después, dentro de Claude Code, /mcp abre el navegador para iniciar sesión.

VS Code

En .vscode/mcp.json del proyecto:

{
  "servers": {
    "ocr": { "type": "http", "url": "{{ mcp_url }}" }
  }
}

Cursor

En ~/.cursor/mcp.json o .cursor/mcp.json del proyecto:

{
  "mcpServers": {
    "ocr": { "url": "{{ mcp_url }}" }
  }
}

Claude Desktop y claude.ai

Se agrega como conector personalizado con la URL del servidor. Estos conectores se conectan desde la nube del proveedor: exigen una URL pública con HTTPS y no funcionan con 127.0.0.1.
