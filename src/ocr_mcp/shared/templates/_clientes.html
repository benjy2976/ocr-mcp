Cómo se conecta un cliente

URL del servidor: {{ mcp_url }}

Hay dos formas de conectarse con la misma clave (docs/integracion-con-clientes.md):

  • Con inicio de sesión (OAuth): se agrega solo la URL; en la primera conexión el cliente abre el navegador y la página pide la clave. El cliente recibe y renueva su token.
  • Con la clave como token: la clave va en el encabezado Authorization: Bearer <clave>. Sirve para clientes sin OAuth, agentes y scripts. La clave queda guardada en la configuración del cliente: trátala como una contraseña.

Claude Code

claude mcp add --transport http ocr {{ mcp_url }}

Después, dentro de Claude Code, /mcp abre el navegador para iniciar sesión. Con la clave como token:

claude mcp add --transport http ocr {{ mcp_url }} --header "Authorization: Bearer <clave>"

Codex

Con la clave en una variable de entorno (por ejemplo, OCR_MCP_KEY) disponible al abrir Codex:

codex mcp add ocr --url {{ mcp_url }} --bearer-token-env-var OCR_MCP_KEY

O en ~/.codex/config.toml:

[mcp_servers.ocr]
url = "{{ mcp_url }}"
bearer_token_env_var = "OCR_MCP_KEY"

VS Code

En .vscode/mcp.json del proyecto. Sin headers e inputs, usa el inicio de sesión:

{
  "servers": {
    "ocr": {
      "type": "http",
      "url": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer ${input:ocr-clave}" }
    }
  },
  "inputs": [
    { "type": "promptString", "id": "ocr-clave", "description": "Clave de ocr-mcp", "password": true }
  ]
}

Cursor

En ~/.cursor/mcp.json o .cursor/mcp.json del proyecto. Sin headers, usa el inicio de sesión:

{
  "mcpServers": {
    "ocr": {
      "url": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer <clave>" }
    }
  }
}

Cualquier otro cliente o script

curl -H "Authorization: Bearer <clave>" -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" {{ mcp_url }} \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"prueba","version":"1"}}}'

Claude Desktop y claude.ai

Se agrega como conector personalizado con la URL del servidor e inicio de sesión. Estos conectores se conectan desde la nube del proveedor: exigen una URL pública con HTTPS y no funcionan con 127.0.0.1.
